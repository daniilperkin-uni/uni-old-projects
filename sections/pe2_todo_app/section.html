PE2 Todo App

A full-stack Todo web app: a Vue 3 + TypeScript SPA on a Spring Boot 4.1 REST API with MariaDB in Docker — and a trained ML classifier that sorts every todo title into work or private as it is saved.

The classifier — running in your browser

The backend loads model.pmml (a 38-token TF-IDF linear model, logit-normalized) through JPMML and classifies each todo on create and update — the statistics view splits by the resulting category. This widget runs the same model's arithmetic in JS, ported token-by-token from the PMML: tokenize → idf × coefficient per matched token → signed score → class. Try the chips, or type a title like team car and watch which side of the line it lands on.

What it does

  • Todos CRUD + assignment — description, LOW/MEDIUM/HIGH priority, assignees resolved server-side; validation failures come back as RFC 7807 ProblemDetail.
  • Kanban board in sync with the finished flag — finishing from the list or dragging a card to DONE keeps status and flag consistent; both write paths are pinned by tests.
  • Recurring todos — WEEKLY/MONTHLY with month-end clamping; finishing spawns exactly one successor, and a repeated DONE move never duplicates it.
  • Overdue-friendly due dates — a new due date must be in the future, but an already-overdue todo stays editable and finishable.
  • ML category + feedback loop — every title is classified; recorded priority corrections are training data for a future retrain of the model.
  • Stats & exports — completion rate, average days to finish, per-priority/category/assignee breakdowns, and CSV downloads.
